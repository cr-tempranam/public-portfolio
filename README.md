## MIS PROYECTOS

En las carpetas que hay continuación, podrá visualizar una serie de prácticas y proyectos que fui desarrollando a lo largo de mi aprendizaje autodidacta. 
Entre ellos:
1. Una recopilación de algunas prácticas realizadas en el lenguaje de programación C a través de Visual Studio Code. En ellas se puede ver el uso de conceptos como bucles, recursividad, funciones, arrays, memoria dinámica, punteros y estructura, entre otros.
2. Un proyecto integrador, tambien realizado en C que consiste en un generador y un graficador de señales utilizando series de Fourier.
3. Una serie de carpetas con proyectos utilizando Power BI. Concretamente en una de ellas se usa mucho las funciones DAX para la creación de medidas. En el resto se ponen en práctica conocimientos como el `ELT` para edición y transformación de datos a través de `Power Query`, modelado de datos y cardinalidad, y el uso de diversos objetos visuales para la presentación de dashboards.
4.  Un apartado destinado a diversas prácticas de base de datos y SQL. En ellas se utilizan varios comandos para la obtención de información específica. Algunos de estos comandos son `SELECT`, `FROM`, `JOIN`, `WHERE`, `GROUP BY`, `ORDER BY`, etc.

Se aconseja leer  primero los archivos "README.md" o aquellos con formato ".md" que contiene cada una de las carpetas para una correcta comprensión de los proyectos y su ejecución.

Con el tiempo se sumarán nuevos proyectos que incorporarán otras tecnologias ampliando el horizonte de conocimiento.
